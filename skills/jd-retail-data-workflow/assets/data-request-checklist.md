# JD data request checklist

- Business question and required output
- Operating mode: AUDIT / COLLECT / ANALYZE / EVIDENCE
- Industry, category path, brands, stores, and product scope
- Business identity: industry / POP `vender` / VC `supplier` / `userPin`
- Recent-history window
- Same-period-last-year window
- Future-season analogue and prior analogue
- Grain: day / week / month / SKU / SPU / brand / store / keyword / attribute
- Metrics and exact units
- Required Shangzhi modules and exports
- Candidate official APIs and permission state
- Existing user files and their coverage
- Promotion and launch annotations
- Delivery format and evidence-link requirements
- Known gaps, fallbacks, and stop conditions
