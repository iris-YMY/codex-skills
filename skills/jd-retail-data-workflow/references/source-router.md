# Source router

| Requested object | Primary source | Secondary source | Do not substitute |
|---|---|---|---|
| Industry size and growth | Shangzhi industry overview/export | User-provided historical files | Own-store GMV |
| Industry product/brand/store ranking | Shangzhi ranking modules/export | Visible page values | Own-store SKU rank |
| Search heat, rising terms, new terms, conversion | Shangzhi keyword modules/export | Search trend files supplied by user | Marketplace web-search popularity |
| Industry price band or attribute share | Shangzhi industry feature/export | Product titles as weak qualitative context | Category attribute dictionary |
| Industry forecast | Shangzhi forecast module | Seasonal model built from matched historical periods | Own-store forecast |
| Own POP store traffic and sales | Authorized official API or Shangzhi store export | User order/traffic files | Industry market data |
| VC/self-operated supplier performance | Supplier-specific API/report or Shangzhi export | User finance/inventory files | POP order or ranking APIs |
| Own product attributes and images | Authorized product API | Product master/export | Industry attribute share |
| Category attribute vocabulary | Official category APIs | Product master taxonomy | Attribute performance |

If the primary source is unavailable, document the gap and downgrade confidence. Never imply that a secondary source measures the same object unless its scope and metric are compatible.
